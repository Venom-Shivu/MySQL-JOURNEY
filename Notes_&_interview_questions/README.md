Welcome to the **Notes** section of the MySQL Journey repository! 🎓

This folder contains a curated collection of study materials, handwritten notes, and interview resources designed to complement the practical SQL scripts found in the main codebase. Whether you are revising for an exam or preparing for a technical interview, these resources are here to help.

> **Note:** These notes contain **sample codes and summaries**. For detailed code implementations and extensive practice, please refer to the **`SQL-Code/`** folder.

### 📝 Phase 1 & 2: The Foundation (Handwritten)
*   **Format:** Scanned Handwritten Notes
*   **Topics Covered:**
    *   Database Basics (DDL, DML, TCL)
    *   `SELECT` statements and filtering
    *   Joins and Subqueries
    *   Aggregations and Grouping

### 💻 Phase 3 & 4: Advanced Mastery (Digital Summaries)
*   **Format:** Computer-written PDF Summaries
*   **Topics Covered:**
    *   Window Functions (`RANK`, `LEAD`, `LAG`)
    *   Common Table Expressions (CTEs) & Recursive Queries
    *   JSON Data Handling
    *   Performance Tuning (`EXPLAIN`, Indexing)
    *   Database Security & Administration
*   *Deep dives into complex topics with syntax examples and performance tips.*

### 💼 Interview Preparation
*   **File:** `Interview_questions.docx`
