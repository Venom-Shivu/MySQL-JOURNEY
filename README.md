## 📚 Curriculum (Located in `SQL-Code/`)

### 🟢 Phase 1: The Basics
*   **00_setup_database.sql** - Initial database and table creation.
*   **01_insert_users.sql** - Populating the database with dummy data.
*   **02_ddl_dml_basics.sql** - Learning DDL (Create/Alter), DML (Insert/Update/Delete), and TCL (Transactions).
*   **03_select_functions.sql** - Mastering `SELECT`, filtering, and built-in functions (String, Date, Math).

### 🟡 Phase 2: Intermediate SQL
*   **04_aggregations.sql** - Grouping data (`GROUP BY`), `HAVING`, and `CASE` statements.
*   **05_setup_addresses.sql** - Setting up relational tables (One-to-Many).
*   **06_setup_admin.sql** - Creating secondary tables for joins.
*   **07_joins_subqueries.sql** - Mastering Inner/Left/Self Joins, Unions, and Subqueries.
*   **08_setup_audit_log.sql** - Preparing tables for triggers.
*   **09_advanced_objects.sql** - Views, Indexes, Stored Procedures, and Triggers.

### 🔴 Phase 3: Advanced SQL
*   **10_advanced_window_functions.sql** - Analytics with `RANK`, `DENSE_RANK`, `LAG`, `LEAD`.
*   **11_advanced_ctes_recursive.sql** - Common Table Expressions and Recursive queries.
*   **12_advanced_json_handling.sql** - Working with JSON data types in MySQL.
*   **13_advanced_performance_tuning.sql** - Optimizing queries using `EXPLAIN` and `EXPLAIN ANALYZE`.
*   **14_advanced_security.sql** - User management, Permissions (`GRANT`/`REVOKE`), and Roles.

### 🔵 Phase 4: Professional Skills & Extras
*   **15_delete_vs_truncate_vs_drop.sql** - Critical interview concepts explained.
*   **16_backup_restore.sql** - Logical (`mysqldump`) vs Physical backups.
*   **17_final_project.sql** - **The Final Boss**: A comprehensive challenge testing all skills.
*   **17_final_project_solution.sql** - Solutions for the final project challenge.

### 📂 Study Notes
*   **Notes/** - Contains study materials:
    *   **Phase 1 & 2**: Scanned handwritten notes covering basics to intermediate topics.
    *   **Phase 3 & 4**: Computer-written PDF summaries for advanced topics.
    *   **Interview_questions.docx**: Common SQL interview questions and answers.

## 🛠️ How to Use

### 1. Clone the Repository
Open your terminal or command prompt and run:
```bash
git clone https://github.com/Venom-Shivu/MySQL-JOURNEY.git
cd MySQL-JOURNEY
```

### 2. Run the SQL Scripts
You can run these scripts in **MySQL Workbench**, **DBeaver**, or the command line.
*   Start with `00_setup_database.sql` to initialize the environment.
*   Proceed through the files in order.
